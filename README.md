# Kolkata Roll Point — Daba Gardens

A **Retro 80s Bollywood × Rajasthani Royal** fast-food centre website for **Kolkata Roll Point** (Daba Gardens), featuring interactive **click-to-elaborate typography**, custom retro poster artwork, a complete menu of **Kathi Rolls, Dum Biryani, and Disco-Wok Fried Rice**, and a cinema ticket-stub ordering experience.

## Features
- **Retro 80s Bollywood × Rajasthani Design**: Marquee bulb header, marigold *toran* garland, cusped *jharokha* arch frames, *jaali* lattice dividers, 35mm film-strip dialogue reel, and `Shrikhand` retro display lettering.
- **Click-to-Elaborate Typography**: Click any hero headline, subtitle, section banner, dialogue card, or dish title to expand its lettering, reveal Rajasthani flourishes, and view full dish stories and ingredients.
- **Complete Menu (23 Dishes)**:
  - **9 Kathi Rolls** (Veg, Egg, Chicken, Mutton Kosha, Cheese Melt, Maharaja Jumbo)
  - **6 Royal Dum Biryanis** (Veg, Egg, Kolkata Chicken Dum, Angara Tikka, Mutton Dum, Special Double)
  - **8 Disco-Wok Fried Rices** (Veg, Schezwan, Burnt Garlic Paneer, Egg, Chicken, Triple Mixed, Maharaja Triple Schezwan)
- **Box Office Food Ticket Cart**: Filter by category/diet, search dishes, choose spice level, toggle add-ons, and generate a showtime order token (`KRP-84-XXX`).

## Run Locally

```bash
python -m http.server 8080
```

Then open `http://localhost:8080` in your browser.
